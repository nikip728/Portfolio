This project was part of a course on Udemy called "Figma UI UX Design Essentials." Here we learned all the tools and concepts beginner designers might need. These were demonstrated and taught to us through creating an app design process. The prompt was randomized for everyone—I got surfboards and my design had to be trendy. We had to create a design for both phone and PC, with the focus on the first of the two.
