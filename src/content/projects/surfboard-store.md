## Brief

This project was my introduction to UI/UX design through the Udemy course “Figma UI UX Design Essentials.” Each student received a randomised prompt. Mine was to design a surfboard store with a trendy visual direction.

## Design approach

The course introduced beginner design tools and concepts through an app-design process. I applied those lessons to a shopping interface, working on both phone and desktop designs with the primary focus on mobile. The brief provided a concrete context for practising Figma while considering how the same store could be presented at different screen sizes.

## Deliverable

The outcome was a course-based interface design, presented in the linked Figma prototype. It is a design exercise rather than a working online store. This project does not document customer research, usability testing, or commercial results.

## Reflection

The value of this first project was learning to translate a defined product category and visual direction into an interface. It provided a starting point for further UI/UX work, while leaving open the question of how well the design would serve real surfboard shoppers. Evaluating shopping tasks with potential customers would be a next step beyond the course exercise.
